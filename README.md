# To Do List Electron

🇺🇸 English

A desktop To Do List application built with Electron, HTML, CSS and JavaScript.

Features include:
- retro/pixel art inspired interface
- custom titlebar
- task management system
- automatic localStorage saving
- task and XP counters
- old-school software inspired visuals and animations

---

## Technologies Used

- Electron
- HTML5
- CSS3
- JavaScript

---

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/miguelotth/to_do_list.git
```

### 2. Open the project folder

```bash
cd to_do_list
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the application

```bash
npm start
```
